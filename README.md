# StructForge

A comprehensive full-stack project combining a React frontend with TypeScript, a Python backend, and a CLI core component.

## Project Structure

- **frontend/**: React + TypeScript + Vite application with modern development setup
- **backend/**: Python-based backend service
- **cli-core/**: Command-line interface core module

## Tech Stack

- **Frontend**: React, TypeScript, Vite (74.3%)
- **Backend**: Python (23%)
- **Styling**: CSS (2.1%)

## Getting Started

### Frontend Setup
```bash
cd frontend/StructForge/structforge
